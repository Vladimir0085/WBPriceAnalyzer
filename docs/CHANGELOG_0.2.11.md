# WB Price Analyzer 0.2.11

- В Windows ZIP добавлена полная PDF-инструкция на русском языке.
- В инструкции описаны быстрый старт, комплект документов WB, старый и новый
  форматы отчётов и правила для неполных периодов.
- Зафиксирован приоритет последнего способа выбора отчётов и синхронизация вкладок
  «Обзор», «Исходные файлы», «Разбивка» и «Сценарий цены».
- Добавлены описания основных формул, сценария цены, экспорта, резервных копий и решения
  типовых проблем.
- Формулы финансового результата и комиссия нетто не изменены.
