# WB Price Analyzer 0.2.10

- Верхний список отчётов снова переключает «Обзор» на один отчёт после
  ранее заданного множественного выбора.
- Кнопка «Выбрать отчёты…» включает множественный режим. Приоритет имеет
  тот способ выбора, который применён последним.
- Один активный набор отчётов теперь синхронно используется вкладками
  «Обзор», «Исходные файлы», «Разбивка» и «Сценарий цены».
- Для нескольких отчётов «Сценарий цены» показывает сводные показатели. Запись
  плановых цен доступна только когда активен один отчёт.
- Формулы финансового результа и комиссия нетто не изменены.
