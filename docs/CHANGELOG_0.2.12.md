# WB Price Analyzer 0.2.12

- Артикулы из отчётов Wildberries теперь сопоставляются со справочником без
  учёта регистра: `ABC-123`, `abc-123` и `Abc-123` считаются одним товаром.
- Каноническое написание артикула из справочника сохраняется в расчётах,
  истории и экспорте.
- Единое правило применяется к основным детализированным отчётам, отчётам
  «по выкупам», уведомлениям о выкупе, поиску неизвестных товаров и пересчёту
  сохранённой истории.
- Неизвестные артикулы, отличающиеся только регистром, объединяются в одну
  позицию. Решение «Пропустить» также применяется без учёта регистра.
- Если в самом справочнике одновременно существуют артикулы, различающиеся
  только регистром, программа выводит понятную ошибку вместо неоднозначного
  распределения операций.
- Обновлены Windows-памятка и PDF-инструкция пользователя.
