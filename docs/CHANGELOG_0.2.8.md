# WB Price Analyzer 0.2.8

- Добавлена автоматическая поддержка нового формата еженедельного
  детализированного отчета WB.
- Сохранена совместимость со старым форматом отчета.
- Поддержаны новые названия столбцов доставки, перемещения и операционной
  обработки товара, а также коэффициента доставки.
- Период отчета определяется по фактическим датам продаж внутри основной
  недели. Однодневный отчет больше не растягивается до семи дней и показывается
  одной датой.
- Основной отчет и отчет по выкупам с разными фактическими диапазонами внутри
  одной недели по-прежнему объединяются в один расчет.
- Перерасчет истории исправляет периоды ранее загруженных отчетов и обновляет
  только автоматические названия, не меняя пользовательские.
- Формулы финансового результата и комиссии нетто не изменены.
